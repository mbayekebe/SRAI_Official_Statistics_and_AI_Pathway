# SRAI Official Statistics and AI Pathway

This repository contains the controlled programme, institutional instruments, learning modules and release records for the SRAI Official Statistics and AI Pathway.

The pathway prepares official statisticians and enabling professionals to use artificial intelligence in statistically defensible, reproducible, secure and institutionally accountable ways.

## Structure

- `programme` — pathway architecture, competencies and governance
- `institutional-toolkit` — diagnostic and implementation instruments
- `modules` — controlled learning modules
- `source-baseline` — preserved source documents and workbooks
