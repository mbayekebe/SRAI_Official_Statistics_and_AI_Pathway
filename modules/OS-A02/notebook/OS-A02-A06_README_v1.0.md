## Run

Place both CSV files beside the notebook, install the packages in `requirements.txt`, and run all cells from top to bottom. The unexecuted notebook is the learner copy; the executed notebook is the validated reference copy.

## Scope

All records are synthetic. The classification result is a pedagogical recommendation, not authority to deploy AI or release official statistics. Human institutional review remains mandatory.
